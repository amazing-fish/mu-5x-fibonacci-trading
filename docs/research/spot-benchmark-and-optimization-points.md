# 现货基准、牛熊失效剖析与下一代优化点清单

> **核心结论（先看全景）**
> 1. **牛市阶段（`2026-03-04 → 2026-06-25`，113.27 天）**：`1x Spot Buy & Hold`（注：仓库内仅有 `MU-USDT-SWAP` 永续价格序列，本文全部"现货 1x"基准均采用**永续价格、零资金费代理口径**，未计量独立现货序列与现永基差）暴涨 **`+228.31%`**（仓库 142.46 天快照为 **`+149.31%`**），碾压全部主动策略——连 5x 分批加仓的 `baseline` 也仅录得 `+36.38%`（按实测均值估算资金费后 `+35.48%`），去掉 5x 杠杆后的 `baseline_1x_lev` 更是仅有 **`+8.19%`**。
> 2. **暴跌波段大反转（`2026-06-25 → 2026-11-21`，149.19 天，峰谷 `-53.37%`）**："无脑拿 1x 多头/开杠杆"彻底崩塌——`1x Spot`（永续价零资金费代理）单段大亏 **`-50.04%`**（全周期收益腰斩回吐至 `+64.28%`，Calmar 跌至 `1.22`），而 **`2x`、`3x`、`5x` 逐仓买入持有（Isolated B&H）从高点全部触发 `-100%` 爆仓归零**；慢速纯多趋势与无波动率过滤的隔夜策略在双底假反弹中同样大失血（`-22.19%` 至 `-46.42%`）。
> 3. **全天候综合标杆（多空双向 + 波动率定仓）**：在牛市段、暴跌段、94 天 100% 实测资金费窗口及 262.45 天全周期全部 4 个维度均保持资金费后正收益的策略，包括多空趋势阵营的 `ls_tsmom_96h`（`+138.20% / +10.32% / +9.26% / +141.49%`）、`ls_breakout_168h`（`+58.89% / +21.07% / +8.55% / +124.13%`）与 `vt_tsmom_96h_ls`（`+42.74% / +11.28% / +7.27% / +55.99%`），以及少数靠 Stage-4 抓到熊市反抽的 Fibonacci 变体（但暴跌期胜率仅 `6.5%–10.3%` 且暴跌期 `ExT3` 深度为负）。若同时叠加**风控与稳健性判据（具备双向做空与正资金费顺风、全周期最大回撤控在 `-20%` 以内且全周期 `ExT3 > 0`）**，则只有 **`vt_tsmom_96h_ls`** 一枝独秀：全周期 MaxDD 仅 **`-17.38%`**、`ExT3 = +1,108 USD`、近零市场 Beta（`-0.04`）和全场最高 `t(Alpha) = +1.86`（相比之下，`ls_tsmom_96h` 全周期 MaxDD 达 `-46.67%` 且 `ExT3 = -415 USD`，`ls_breakout_168h` 全周期 MaxDD `-31.07%` 且 `ExT3 = -924 USD`）。
> 4. **演进方向**：下文第 3 节给出可直接落地的 **P0 / P1 / P2 优化点清单**，逐项挂钩 Phase 1–3 Strategy Backtest Lab 路线图与仓库现有 GitHub Issues（`#73`、`#101`、`#129`）。

## 1. 牛市解剖：为什么 1x 现货（零资金费永续代理）碾压了全部主动策略？

在 `2026-03-04` 至 `2026-06-25` 的主升浪（以及仓库基线快照 `2026-03-04 → 2026-07-24`，142.46 天）中，`MU-USDT-SWAP` 从 `373.12 USD`（3 月 31 日低点 `314.00 USD`）飙升至 `1,257.08 USD`，实现年化波动率高达 `91.1%–93.3%`。需要说明的是，由于仓库仅保存 `MU-USDT-SWAP` 永续合约 K 线、不含独立美股现货行情，下文牛市与暴跌回撤章节中的 `1x Spot`（`1x_spot_bh`）均表示**基于永续价格路径、资金费置零的 1x 持有代理（未计量现永基差）**。将主动策略与该 1x 代理逐层拆解对比，可以精准定位 **6 项独立可量化的收益漏斗**：

### 1.1 漏斗一：极低的资金在场率（`TIM% ~21%`），系统性踏空主升浪

- 牛市阶段 `baseline` 仅 **`20.8%`** 的时间持有头寸（全周期 `20.2%`），近 **`80%`** 的时间空仓观望，直接错过了 4 月（`+47.44%`）与 5 月（`+95.45%`）最暴力的单边拉升。
- 剥离 5x 杠杆伪装后看真实单倍捕获率：在标的大涨 `+228.31%` 的牛市里，`baseline_1x_lev` 仅赚 **`+8.19%`**，`smooth_1x_lev` 仅赚 **`+14.49%`**（142 天快照下二者分别为 `+11.81%` 与 `+18.33%` vs Spot `+149.31%`）。5x 杠杆只是在掩盖极低的资产趋势捕获效率。

### 1.2 漏斗二：入场被硬锁在"高噪音、负漂移"的美盘窄窗口

- 现有 Fibonacci 策略仅允许在美东 `09:45–11:30` 与 `14:30–15:45`（`us_cash_strat_win`）建仓。该时段仅占全天 `10.17%` 时间，却承载全市场最高的日内扫荡噪音（15m 均振幅 `1.044%` / RMS `78.0 bps`，142d 为 `1.145%` / `84.9 bps`）。
- 牛市期间该窗口仅涨 `+18.37%`（142d 甚至为 **`-0.51%`**，全周期 **`-22.35%`**），而美股盘外在牛市贡献了 **`+152.71%`**（全周期 `+106.98%`）。
- 142 天逐笔核查发现，Fibonacci 策略全部 `6` 笔盈利单中有 **`4` 笔**（`Mar 13`、`May 1`、`May 29`、`Jul 17`）是周五入场后**偶然跨周末持仓**吃到盘外漂移，其余时间几乎全部在美盘高噪音窗口中反复止损（详见 [收益错配深度观察与风险排查](session-return-mismatch-and-risks.md)）。

### 1.3 漏斗三：`signal_candle.low` 初始止损缺陷，触发 ~28% 同根 K 线即刻止损（`SBSO`）

修复回测逻辑后的消融审计暴露出一个核心策略设计缺陷：

- `resolve_initial_stop` 规定 `signal.stop_price = max(hard_stop, signal_candle.low)`。在 142 天实测中，这一规则覆盖了 `baseline` **`61.7%`（`29/47`）** 的常规 `-2%` 硬止损——将 **`38.3%`（`18/47`）** 的初始止损压缩到窄于 `-0.5%`，把 **`29.8%`（`14/47`）** 压缩到窄于 `-0.2%`（最极端仅 **`0.004%`**，中位数仅 **`0.737%`**），而美盘 15m 单根 K 线平均振幅高达 `1.145%`！
- 由于 `second_pullback` 在 `fib_level` 挂限价买单成交后，在同一根 15m K 线上立刻执行 `_exit_on_risk` 校验（且无 15m 内部逐笔先后路径信息），导致 **`27.0%–29.7%`** 的入场在**成交的同一根 K 线上瞬间止损（Same-Bar Stop-Out, `SBSO`）**：牛市 `10–11/37` 笔、142d `14/47`（`29.8%`）、全周期 `21–22/76` 笔（`~28%`；`smooth` 142d `15/47`，`direct_next_open` `19/60`）。
- 24 小时前瞻验尸证明这是一把需要修理的"钝刀"：142 天 `14` 笔 SBSO 中虽然有 `10` 笔在 24 小时内最终跌破 `-2%`（所以收紧止损确实把 `baseline` DD 从 `-35.42%` 压到 `-23.90%`），但有 **`5` 笔先大涨 `>= +4%`**（其中两笔在从未碰过 `-2%` 前直接飙升 **`+11.31%` 和 `+11.71%`**），直接洗掉了 `smooth` 的 `2` 笔 Stage-4 大赢家——只需增加一个最小 `0.5%` 止损下限，`smooth` 142d 收益立刻从 `+100.24%` 跳升至 **`+131.57%`**（同时维持 `-22.64%` DD、PF 由 `2.22` 升至 `2.42`）。

### 1.4 漏斗四：100% 盈利集中于 Stage-4 彩票单（非 Stage-4 零胜率）

- 在整个 `262.45 天`全周期内，`baseline` 全部 **`8/8`** 盈利交易、`smooth` 全部 **`9/9`** 盈利交易、`green_wide` 全部 **`9/9`** 盈利交易，**100% 是打满 Stage-4 的金字塔加仓单**。
- 所有未能滚到 Stage-4 的 Stage 1–3 交易，**全部以亏损告终**：`smooth` 非 Stage-4 胜率 **`0/67`**，`baseline` 为 **`0/68`**，`green_wide` 为 **`0/66`**（142d 快照下同样为 `0/40–42`）。
- 只要剔除收益最高的 3 笔幸运交易（`ExT3`），全周期 `baseline` 立刻倒亏 **`-5,958 USD`**，`smooth` 倒亏 **`-4,986 USD`**，`green_wide` 倒亏 **`-3,313 USD`**（142 天快照下，仓库全部 14 个注册 Fibonacci 预设的 `Top3%` 占比高达 `111%–497%`，无一例 `ExT3 > 0`）。

### 1.5 漏斗五：历史 Bug 幻觉 + `fib_lookback=8` 参数悬崖过拟合

- **先正本清源旧版 `+285.57%`（140d `+293.83%`）高收益幻觉**：逐项消融实验证明，`HEAD 0c24a45` 旧版超高收益的 ~85% 来自 `recent_swing` 未校验 `low_index < high_index` 的代码 Bug——导致 46 笔 `baseline` 交易里有 `15` 笔根本不是上升波段回调，而是 2 小时急跌后的逆势抄底反弹（恰好撞上单边大牛市大赚 `+8,418 USD` 原始利润并复利滚雪球）。修复该 Bug 后策略暴露出真实盈利能力（`+285.57% → +55.31%`）。
- **`fib_lookback=8` 参数悬崖**：`presets/fibonacci.py` 把 MU 硬编码为 `fib_lookback=8`（2 小时，源于 Bug 修复前短短 7 天的扫描）。142 天测试显示 `lb=8`（`+55.31%`）紧挨着悬崖——隔壁 **`lb=10` 收益断崖崩塌至 `+10.21%`（PF `1.20`）**；而放大到更稳健的参数高原后全线飙升：`lb=16`（`+102.1%`）、`lb=24`（`+122.1%`）、**`lb=32`（142d `+144.84%`, DD `-18.55%`, PF `5.37`, `ExT3 = +763 USD`；全周期 262d `+138.96%`, Calmar `6.61`）**，其中 `smooth_lookback32` 全周期更是达到 **`+185.79%`**（实盘资金费后 `+182.93%`、Calmar `7.84`、且 `ExT3` 翻正至 **`+521 USD`**）。在 90%+ 波动的标的上，2 小时回看几乎全是随机噪音。

### 1.6 漏斗六：高换手 + 5x 杠杆放大手续费与滑点摩擦

- 全周期 262.45 天内，`1x Spot B&H` 仅交易 1 次、支付手续费 **`13.22 USD`**（牛市段 `21.43 USD`，142d `17.47 USD`）；而 `baseline` 在 68 笔 Stage-1/2 止损来回折腾中共支付 Taker 手续费 **`1,573.94 USD`**（`smooth` 为 `2,020.42 USD`，`green_wide` 为 `2,256.03 USD`），费用摩擦是现货的 **`119–171` 倍**。
- 5x 杠杆会把单边滑点同步放大 5 倍（一进一出 Stage-4 相当于吞噬 ~`50 bps` 净值/每 `5 bps` 单边滑点）。142 天滑点敏感性实验显示，单边滑点升至 `20 bps` 时，`baseline` 收益直接从 `+55.3%` 腰斩再腰斩至 **`+15.0%`**（`direct_next_open` 从 `+56.2%` 崩至 `+7.3%`）。

### 3.2 推进顺序与执行纪律

1. **先修尺子，再找圣杯（P0 先行）**：在回测引擎未接入各合约真实历史资金费率（按实际结算时间戳）、动态滑点与随机安慰剂门禁之前，任何"看起来很美"的新策略收益都可能是微结构幻觉（`#129` 必须先于策略扩张落地）。
2. **解耦协议而非盲目造大平台（P1 对齐 `#101`）**：优先只做有明确第一性原理支撑的少数高信噪比策略族（多空波动率目标趋势 + 时段微结构对齐），每一族使用完全同一套真实成本模型与评估契约公平竞技。
3. **跨标的达标前绝不碰实盘（P2 守住 `#73` / `#7` 红线）**：单一标的 8 个多月的历史无论收益多高都无法证伪运气成分；只有跨标的面板、跨牛熊周期、扣除全部真实成本后依然站稳统计显著性红线的策略，才配获得 S2 受控 Demo 与后续实盘的入场券。
