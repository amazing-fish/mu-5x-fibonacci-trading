# 收益错配深度观察与非美盘（隔夜/周末）风险排查

> **核心结论（先看判词）**
> 1. **收益错配在牛熊全周期均结构性成立**：在 `2026-03-04` 至 `2026-11-21`（`262.45 天`、含 `-53.37%` 双底暴跌波段）的完整实盘周期中，美股常规交易时段（US Cash）累计收益为 **`-21.01%`**，其中策略专属入场窗口 `us_cash_strat_win`（美东 `09:45–11:30` 与 `14:30–15:45`）单独亏损 **`-22.35%`**（暴跌波段单段大亏 **`-34.41%`**）；而美股盘外（`weekday_non_cash` + `weekend_sat_sun`）累计收益高达 **`+106.98%`**——**超过 `100%` 的全周期涨幅发生在美股休市时段**。

> 3. **策略确认门禁（NO-GO 判据）**：**严禁直接部署未过滤的纯隔夜/周末做多策略**。在通过波动率封顶（如 `90%` 年化波动率上限已将暴跌期亏损从 `-22.19%` 压缩至 `-1.42%`）、趋势状态门控、财报窗口禁入、OKX 真实 8 小时资金费率与动态滑点建模以及跨标的样本外验证之前，任何隔夜/盘外策略均不得进入模拟盘或实盘候选。

### 2.2 核心发现与暴跌波段现实检验（Crash-Wave Reality Check）

1. **为什么策略主窗口沦为"高噪音绞肉机"？**
   - `us_cash_strat_win` 仅占全天 `10.17%` 的时间，却集中了全市场 `27.80%` 的成交额，平均每 15 分钟振幅高达 `1.044%`（RMS `78.0 bps`），是 `weekday_non_cash` 噪音的近 `2` 倍、周末的 `3` 倍以上。
   - 这一窗口恰好覆盖美股开盘后首轮多空激战（`09:45–11:30`）与尾盘再平衡（`14:30–15:45`），机构现货与期权对冲盘密集释放，导致价格剧烈双向扫荡、均值回归占主导。牛市里它仅贡献 `+18.37%`，一进暴跌期便成为核心派发砸盘口（单段暴跌 **`-34.41%`**），全周期累计 **`-22.35%`**。
   - 讽刺的是，在 142 天审计中，Fibonacci 策略盈利的 `6` 笔交易里竟有 `4` 笔（`Mar 13`、`May 1`、`May 29`、`Jul 17`）是周五入场后**意外跨周末持仓**才吃到的盘外漂移，而在盘内反复止损消耗了绝大部分利润。

2. **暴跌波段的现实检验：相对价差成立，绝对漂移失效！**
   - **好消息（结构性价差未消失）**：即便在 `-53.37%` 的大暴跌波段里，美盘与盘外的相对强弱剪刀差依然存在——美盘跌了 **`-39.70%`**（`us_cash_strat_win` 独跌 `-34.41%`），而盘外跌幅不到美盘一半（`-18.09%`），周末甚至微涨 `+1.50%`。全周期看，`Non-Cash` 累计 `+106.98%` vs `US Cash` 累计 `-21.01%`，相对结构高度一致。
   - **坏消息（单边盘外做多在熊市照样大亏）**：盘外并非"永涨保险箱"。在暴跌波段中，`weekday_non_cash` 依然下跌 **`-19.30%`**；周末的绝对表现也出现断崖退化——牛市 `16` 个周末胜率高达 **`87.5%`**、均值 **`+3.632%`**，到了暴跌波段 `21` 个周末胜率骤降至 **`52.4%`**、均值转负至 **`-0.275%`**。因此，把"盘外相对强于盘内"误读为"无条件隔夜做多稳赚"，在熊市里会付出惨痛代价。

## 4. 策略确认门禁（Strategy Confirmation Gate）

基于以上全部实证审计，本仓库对"非美盘 / 隔夜策略"设立明确的 **策略确认门禁**：

### 4.1 明确禁止项（NO-GO 红线）
- **严禁直接部署无过滤的纯隔夜/周末做多策略**（`overnight_unfiltered` 暴跌期亏 `-27.68%`、全周期 `t(Alpha) = +0.60`，缺乏统计显著性且承受高额资金费与跳空尾部风险）。
- **严禁对隔夜/周末策略使用固定高杠杆（`>= 2x`）**，单晚 `-11.32%` 与连续暴跌可在高杠杆下引发不可逆毁灭。
- **严禁在未扣除 OKX 真实 8h 资金费率（尤其 `00:00`/`08:00 UTC` 费率）与盘外动态滑点前，将任何隔夜回测收益作为晋升依据**。

### 4.2 候选晋升必须同时满足的 5 项硬条件

| 门禁编号 | 必要条件 | 具体实现标准与量化依据 |
|---|---|---|
| **Gate-1** | **波动率封顶或动态定仓** | 接入实现波动率门控（如年化波动率 `<= 80%–90%` 封顶，已实证将暴跌亏损由 `-22.19% → -1.42%`）或连续 Vol-Targeting 缩仓（如 `20%–30%` 目标年化波动率）。 |
| **Gate-2** | **中期趋势与状态过滤** | 不能仅靠单一 20 日均线（易被熊市反抽诱多）；需结合多周期趋势斜率或 1h/1d 状态机，在下跌主导 regime 中主动空仓或转向空头。 |
| **Gate-3** | **财报与重大宏观事件禁入窗（Earnings Blackout）** | 强制在标的财报发布日前后（如 `T-1` 盘后至 `T+1` 开盘）及 FOMC/CPI 核心窗口禁止持有隔夜裸敞口，彻底隔离类似 `2026-06-24` 单根 `+9.53% / -6.29%` 的二元跳空赌博。 |
| **Gate-4** | **真实资金费率 + 分时段流动性滑点建模** | 回测引擎必须按 `00:00`/`08:00`/`16:00 UTC` 结算真实历史资金费率，并按每根 K 线 USD 成交额动态放大盘外/周末滑点（覆盖 `17.6x` 周末深度衰减）。 |
| **Gate-5** | **多标的横截面与样本外验证** | 单一 `MU-USDT-SWAP` 262 天最高 `t(Alpha)` 仅 `+1.42`（隔夜族），必须扩展至多只美股永续面板（如 `NVDA`、`AAPL`、`TSLA`、`COIN` 等），确认在多标的带隔离期滚动样本外检验（Purged Walk-Forward）中 `t(Alpha) >= 2.0` 且 `ExT3 > 0`。 |
