# 量化策略评估第一性原理：通俗概念与红线判据手册

> **这本手册写给谁？**
> 当你看到一份量化审计报告里蹦出 `p = 0.245`、`t(Alpha) = +0.56`、`IR = -1.58`、`ExT3 = -5,958 USD`、`Deflated Sharpe`、`Purged Walk-Forward` 这些词时，很容易一头雾水："策略明明赚了 `+147%`，怎么还说它没用？"
> 本手册不堆砌数学推导、**不留任何一个未解释的黑话**，只用大白话、生活类比，配上咱们 `OKX MU-USDT-SWAP` 实盘审计（`142.46 天`牛市快照 + `262.45 天`含 `-53.37%` 暴跌全周期 + `283` 次真实 OKX 资金费率）里的真金白银案例，把判断一个策略"到底是真本事还是撞大运"的 7 个核心概念一次讲透。

## 概念 1：蒙特卡洛随机入场安慰剂检验 & `p` 值

> **核心疑问**：为什么 `p = 0.245` 等于"闭着眼睛扔骰子都能赢你四分之一"？

### 一句话直白解释
**安慰剂检验**就是把你精心设计的入场信号拔掉，换成一个"蒙眼随机乱买"的机器人，用完全一样的资金管理、加仓和止损机器重复跑几百遍（这叫**蒙特卡洛模拟**）；**`p` 值**就是"这几百个蒙眼乱买的机器人里，有多少比例最后赚得比你还多"。

### 生活 / 交易类比
就像医院测试一种新感冒药，绝不能只看"吃了药 7 天好了"就宣布有效——因为不吃药喝白开水 7 天也可能自己好。必须找对照组吃**毫无药效的糖丸（安慰剂）**。如果吃新药的恢复速度，居然有 `24.5%` 吃糖丸的人都能超过，那药监局肯定立刻驳回：这药根本没证明比糖丸强。

交易里也一样：你想证明"斐波那契画线选点"真有本事，就得让一群猴子在**相同的交易时段、相同的行情过滤器、相同的 5x 加仓止损机器**下，唯独把"画线选点"换成"随机拍按钮买"。如果猴子随便拍按钮都能赢你，说明赚钱靠的是牛市大环境和加仓机器，而不是你的画线技术。

### 在 `MU-USDT-SWAP` 上的真实案例
在 `data/live`（142.46 天牛市）上，我们对现有策略做了 **200 次蒙特卡洛随机入场实验**（完全锁死相同的美盘时段、1h 绿/黄状态、5x 金字塔和止损机制，只把入场 K 线改成随机抽取）：

- **`baseline`（收益 `+55.3%`）**：面对固定 `-2%` 止损的随机入场猴子，有 **`24.5%` 的随机试验直接赚得比 `baseline` 更多**（`p = 0.245`，随机中位数 `+19.5%`，前 10% 的幸运猴子甚至能赚 `+94.9%` 以上）；即便改用更苛刻的紧止损，仍有 `11.0%` 的随机猴子打败它（`p = 0.110`）。
- **`baseline_delayed_tighten_smooth`（收益 `+100.2%`）**：仍有 `12.5%` 的随机入场打败它（`p = 0.125`）。
- **`baseline_green_wide`（收益 `+147.5%`）**：这已经是仓库 14 个预设里挑出来的第一名，面对随机入场也只有 `p = 0.080`——依然没过 `0.05` 的统计学及格线！

这组实验一锤定音：**斐波那契回调入场本身没有展现出超越随机运气的选点优势**。

### 实战怎么用（红线判据）
- **单策略底线**：同引擎随机入场安慰剂检验必须 **`p < 0.05`**（100 个蒙眼猴子最多只有不到 5 个能偶然赢你）。
- **多策略海选更严**：如果是从 10–100 套方案里挑出的最好结果，红线必须拉高到 **`p < 0.01`**（详见概念 7）。

## 概念 2：CAPM Alpha / Beta / `t(Alpha)` / 信息比率（IR）

> **核心疑问**：为什么策略赚了 `+147%`，量化审计还冷冰冰地说它"没有 Alpha"？

### 一句话直白解释
把这四个词拆成四句人话：
- **Beta（顺风车系数）**：大盘（或 1x 现货）涨 `10%`，你跟着涨多少？这部分是**老天爷赏饭吃**，不是你的本事。
- **Alpha（真实超额本事）**：把"蹭大盘涨跌的顺风车"扣除之后，纯粹靠你的选时、做多做空技巧额外多赚出来的收益。
- **`t(Alpha)`（运气过滤器 / 信噪比）**：把算出来的 Alpha 除以它自身的起伏波动，再乘以样本天数的平方根。就算 Alpha 表面看起来很高，如果净值上蹿下跳、测试时间又短，`t` 值照样很低——说明大概率是碰巧。统计界公认 **`t >= 2.0`** 才大致有 `95%` 把握认为"不是纯运气"。
- **信息比率 IR（相对躺平拿现货的性价比）**：`(策略收益 - 1x 现货收益) / 两者差值的波动率`。**如果 IR 是负数，说明你辛辛苦苦折腾几十笔，还不如第一天买完现货去睡觉。**

### 生活 / 交易类比
你站在一列时速 300 公里的高铁（大盘牛市）车厢里往前小跑：
- 高铁给你的速度 = **Beta**；
- 你自己双腿跑出来的 5 公里/小时 = **Alpha**；
- 如果车厢剧烈颠簸，测速仪测出你前后晃动幅度有 ±15 公里/小时，那么你那点 5 公里/小时的向前移动在统计上根本看不出你是在往前跑还是在原地晃（**`t(Alpha)` 极低**）；
- 如果你其实在往车尾方向倒着走（虽然相对地面你还在以 295 公里/小时飞奔、账户依然在赚钱），你相对"直接坐座位不动（买现货）"的超额性价比就是负的（**`IR < 0`**）！

### 在 `MU-USDT-SWAP` 上的真实案例
- **142 天牛市审计（`1x Spot` 涨 `+149.31%`）**：
  - `baseline` 账面赚 `+55.31%`，`Beta = 0.28`，算出来年化 Alpha 似乎有 `+60.0%`，但净值起伏极大，**`t(Alpha)` 仅有 `+0.56`**（远低于 `2.0`），相对现货的 **`IR = -1.58`**（折腾半天大幅跑输躺平）。
  - 连 14 个预设里表现最炸裂的 `baseline_green_wide`（`+147.51%`），`Beta = 0.35`，**`t(Alpha)` 也只有 `+1.25`**，相对 1x 现货的 **`IR = -0.14`** 依然是负的！
- **拉长到 262.45 天牛熊全周期（含 `-53.37%` 暴跌，`1x Spot` 回吐至 `+64.28%`）**：
  - `baseline` 的 `t(Alpha)` 依然只有 **`+0.72`**（`IR = -0.43`）。
  - 反观全天候多空趋势策略 **`vt_tsmom_96h_ls`**，它在牛市做多、熊市做空，把 **`Beta` 压到了 `-0.04`**（彻底不靠大盘涨跌吃饭），**`t(Alpha)` 跃升至全场最高 `+1.86`**！但请注意：`+1.86` 依然略低于 `2.0`，说明仅靠一只股票 8 个半月的数据，离"板上钉钉的真 Alpha"还差最后一口气（需要多标的验证）。

### 实战怎么用（红线判据）
- **真本事及格线**：`t(Alpha) >= 2.0`（跨多标的/长周期样本）；任何 `t(Alpha) < 1.5` 的策略，无论收益率数字多耀眼，本质上都无法区分"天才"和"幸运儿"。
- **纯多策略附加项**：必须对比同周期 `1x Spot` 与等波动 B&H；如果长期 `IR < 0`，说明连最简单的现货基准都没跑赢。

## 概念 3：样本集中度与 `ExT3` / `ExT5`

> **核心疑问**：为什么"扣掉最好的 3 笔交易就倒亏"是足以一票否决的致命红旗？

### 一句话直白解释
- **`Top3%`（头部集中度）**：赚钱最多的 3 笔交易贡献了全部净利润的百分之多少？如果大于 `100%`，意味着除了这 3 笔之外，其余几十笔交易合起来其实是在**亏钱**。
- **`ExT3`（Excluding Top 3，剔除前 3 笔后的净盈亏）**：强行把历史上最幸运的 3 笔大赚单从账本里撕掉，看剩下的交易加起来还能不能赚钱。（`ExT5` 就是撕掉最好的 5 笔。）

### 生活 / 交易类比
你认识一个朋友，半年买了 76 张彩票，其中 73 张都在稳定亏钱，全靠某三个周末撞大运中了 3 次大奖，账面才净赚 4,600 元。他跑来跟你说："我发现了一套稳定复利的买彩票量化系统！"你会投钱吗？

实盘交易里，断网 1 分钟、交易所插针滑点、刚好那天你在开会没确认邮件，哪怕只错过这 3 次超级大行情里的 **1–2 次**，你的实盘结果就会瞬间从"账面大赚"变成"本金腰斩"。

### 在 `MU-USDT-SWAP` 上的真实案例
- **致命红旗反例（Fibonacci 全家族）**：
  - 在 262.45 天全周期里，`baseline` 一共做了 `76` 笔交易，账面赚 `+46.30%`（`+4,630 USD`），但全部 `8` 笔盈利单 **100% 是打满 Stage-4 的金字塔单**，其余未打满 Stage-4 的 `68` 笔交易**无一盈利（`0/68`）**！一旦扣掉最好的 3 笔交易，**`ExT3 = -5,958 USD`**（10,000 USD 本金直接亏掉近六成）！
  - `baseline_green_wide` 账面 `+140.96%`，扣掉 3 笔后依然倒亏 **`-3,313 USD`**；在 142 天快照里，仓库 14 个注册预设的 `Top3%` 全部高达 **`111%–497%`**，没有一个能在去掉 Top 3 后保本！
- **健康结构正例**：
  - 全周期 262.45 天里，真正做到"撕掉最好的 3 笔照样赚钱"的寥寥无几：**`overnight_price20_0930_15m`（`ExT3 = +1,926 USD`）**、**`vt_tsmom_96h_ls`（`ExT3 = +1,108 USD`）**、**`overnight_price20_vol90`（`ExT3 = +942 USD`）** 以及修正回看周期后的 **`smooth_lookback32`（`ExT3 = +521 USD`）**。它们的利润分布在几十笔交易上，而不是押宝两三张彩票。

### 实战怎么用（红线判据）
- **交易笔数底线**：有效独立交易笔数至少 `>= 30–50` 笔（只有 5 笔交易的策略连统计学大门都进不去）。
- **去幸运红线**：强制要求 **`ExT3 > 0`**（样本超百笔时进一步检视 **`ExT5 > 0`**）。凡是 `ExT3` 深度为负的策略，一律按"高脆性彩票"处理，不得重仓实盘。

## 概念 4：参数悬崖 vs 参数高原

> **核心疑问**：为什么 `fib_lookback = 8` 旁边 `lb = 10` 收益断崖暴跌，就说明 `lb = 8` 是过拟合？

### 一句话直白解释
把策略参数画成一张三维地形图，海拔越高代表赚得越多：
- **参数高原**：一片宽阔平缓的山顶平台——参数往左调一点、往右调一点，表现都稳稳当当。
- **参数悬崖**：一根针尖一样的孤峰——只有精确踩在某一个数字上才赚钱，稍微挪动一两格就立刻跌落万丈深渊。

### 生活 / 交易类比
买衣服时，**参数悬崖**就像找裁缝按你今天午饭后精确到 0.1 毫米的腰围死抠出来的一件紧身西装：今天穿上去帅呆了，明天多喝一杯奶茶扣子就崩开。**参数高原**则是一件版型优秀、带弹性剪裁的夹克，你胖五斤瘦五斤都一样合身。

真实市场明天一定会比昨天稍微快一点或慢一点，波动率也天天在变——所以实盘里**踩在"针尖"上的最优参数几乎 100% 必死，只有站在"高原中央"的次优参数才能活下来**。

### 在 `MU-USDT-SWAP` 上的真实案例
仓库早期基于修复 Bug 前短短 7 天的扫描，把 `MU-USDT-SWAP` 的斐波那契回看窗口硬编码锁死在 **`fib_lookback = 8`**（2 小时）。在修复 Bug 后的 142 天测试中，扫描相邻参数直接画出了经典的"悬崖 vs 高原"对比：

| 回看窗口 `fib_lookback`（15m 根数 / 小时） | 142 天收益 | 特征定位 |
|---|---:|---|
| **`lb = 8`（2.0 小时，原 MU 硬编码）** | `+55.31%` | 孤立小尖峰（紧挨悬崖！） |
| **`lb = 10`（2.5 小时，仅挪半小时！）** | **`+10.21%`**（PF 暴跌至 `1.20`） | **典型参数悬崖**——微调即崩塌 |
| `lb = 16`（4.0 小时） | `+102.1%` | 爬上高原坡面 |
| `lb = 24`（6.0 小时） | `+122.1%`（前半 `+48.5%` / 后半 `+49.6%`） | 高原稳健区 |
| **`lb = 32`（8.0 小时，非 MU 通用默认）** | **`+144.84%`**（DD `-18.55%`, PF `5.37`, `ExT3 = +763 USD`） | **宽广参数高原中心**（262d 全周期 `+138.96%`，`smooth_lb32` 高达 `+185.79%` 且 `ExT3 > 0`） |
| `lb = 48`（12.0 小时） | `+207.9%` | 高原延续区 |

真相大白：对年化波动近 `90%` 的芯片股永续来说，2 小时波段几乎全是随机毛刺；`lb = 8` 只是历史巧合，而 `lb = 24–48` 才对应真正有经济含义的日内/跨日结构波段。

### 实战怎么用（红线判据）
- **邻域压力测试**：任何核心参数在上下浮动 **`±20%` 至 `±50%`** 时，盈利因子和夏普不能出现断崖式塌方。
- **选参铁律**：永远选择**参数高原的中心位置**（哪怕它的历史收益不是全表绝对最高），坚决抛弃被亏损深渊包围的"孤峰第一名"。

## 概念 5：永续合约微结构——8h 资金费率、盘中噪音 vs 隔夜跳空、周末薄流动性

> **核心疑问**：为什么永续合约回测不算资金费率、不区分时段深度就是自欺欺人？为什么做空反而是收资金费？

### 一句话直白解释
在加密货币交易所交易美股永续合约（如 OKX `MU-USDT-SWAP`），和在券商买普通美股现货完全是两个物种，必须看清三大微结构真相：
1. **8 小时资金费率（持仓房租）**：永续合约没有交割日，为了防止合约价涨得比现货贵太多，交易所每天固定 3 次（`00:00`、`08:00`、`16:00 UTC`）让做多太拥挤的一方向对手方付息。散户天然爱做多美股科技股，所以资金费率长期为正——**多头每天交 3 次房租，空头躺着收 3 次房租**。
2. **盘中噪音 vs 隔夜跳空**：美股开盘时间（美东 `09:30–16:00`）机构与量化高频扎堆，K 线像锯齿一样来回扫止损（高噪音）却常常不走单边；美股收盘后的 17.5 小时和周末容易走出大方向漂移，但随时可能被盘后财报或突发新闻砸出一步到位的**大跳空**（止损单根本来不及成交）。
3. **周末薄流动性**：周末美股休市、专业做市商撤单，盘口深度骤降十几倍，很小一笔市价单就能把价格砸穿几个点，滑点瞬间爆炸。

### 生活 / 交易类比
把一天 24 小时比作开车送货：
- **美股常规盘** = 早高峰的闹市菜市场，人挤人全是急刹车和剐蹭（高噪音、扫止损），路很宽（流动性好）但走不出直线速度；
- **工作日盘外 / 周末** = 深夜郊区高速，车少路直经常能跑出一大段里程（非美盘漂移），但**没有路灯随时有深坑（隔夜/财报跳空）**、过收费站还要交**高额过夜费（资金费率）**，而且周末路边连修车厂都关门（**17 倍薄流动性**，一脚急刹就能滑出几十米）。

### 在 `MU-USDT-SWAP` 上的真实案例
- **真实 8h 资金费率（OKX 283 次实盘结算，`Aug 19–Nov 21`）**：
  - 哪怕在这 94 天里 MU 暴跌了 `-35.05%`，资金费均值依然高达 **`+0.600 bp/8h`（年化 `+6.57% APR`）**！`44.52%` 的时段为正（最高飙到 **`+16.09 bp/8h`**），`53.00%` 为零，只有 **`2.47%`（7 次）** 为负！
  - 更坑的是，一天里最贵的两次结算恰好是 **`00:00 UTC`（`7.82% APR`）** 和 **`08:00 UTC`（`6.87% APR`）**——每一次美股隔夜持仓都精准撞上这两笔最贵的房租。
  - 账单对比：全周期 `1x_perp_bh` 光资金费就净亏 **`-1,019 USD`**（收益从 `+64.28%` 跌到 `+56.69%`）；反过来，多空策略 **`ls_breakout_168h`** 靠熊市做空在全周期**净收 `+79.81 USD` 资金费**（暴跌波段单段净收 **`+109.22 USD`**）！
- **盘中噪音 vs 隔夜跳空**：
  - 美盘核心入场窗 `us_cash_strat_win` 15m 平均振幅 `1.044%`，全周期累计亏损 **`-22.35%`**（暴跌期独亏 `-34.41%`）；
  - 盘外全周期大涨 `+106.98%`，但 182 次隔夜里有 `18` 次单晚跌超 `5%`，最惨一晚（`Jun 22→23`）收盘 **`-10.77%`**、盘中 **`-11.32%`**；`Jun 24` Q3 财报盘后 15 分钟单根暴涨 `+9.53%`，次日开盘立刻单根暴跌 `-6.29%`。
- **周末 17 倍流动性断崖**：
  - 暴跌期美盘核心窗口 15m 中位成交额高达 **`3.41M USD`**，到了周末直接断崖缩水至 **`194k USD`**（最薄的 10% 时段仅 **`43k USD`**），整整薄了 **`17.6` 倍**！`2026-10-17` 周六下午即发生 15 分钟 **`-5.41%`** 的薄盘口闪崩。

### 实战怎么用（红线判据）
- **资金费强制入账**：永续合约回测若没按真实历史资金费率扣算（多付空收），结果直接作废。
- **滑点与成交额挂钩**：不能拿美盘的 `5 bps` 滑点套用到周末薄盘口；大额策略必须限制周末市价止损与仓位上限。

## 概念 6：固定高杠杆的爆仓数学 & 波动率损耗 vs 波动率目标定仓（Vol-Targeting）

> **核心疑问**：为什么在 `93%` 波动率的标的上开固定 5x 杠杆几乎必爆？什么是波动率损耗？波动率目标定仓又是怎么救命的？

### 一句话直白解释
- **固定高杠杆的爆仓数学**：开 `L` 倍逐仓杠杆，标的只要反向波动大约 `1 / L`（扣掉维持保证金 MMR 甚至更小），你的本金就永久清零、永远没有翻身机会。`5x` 杠杆容错率只有约 **`19%`**。
- **波动率损耗（Volatility Drag）**：涨跌百分比天生不对称——先涨 `50%` 再跌 `50%`，结果不是回本，而是亏掉 `25%`（`1.5 × 0.5 = 0.75`）。波动越大，复利损耗按**波动率的平方**暴增；5x 杠杆把波动率放大 5 倍，损耗就暴增 **`25` 倍**！
- **波动率目标定仓（Vol-Targeting）**：不再死磕固定倍数，而是根据市场当前的颠簸程度动态算仓位：

```text
当前目标杠杆 = 目标年化波动率（例如 30%） / 标的近期实现年化波动率
```

行情风平浪静（波动 `30%`）就开 `1.0x`；行情狂风暴雨（波动 `90%`）自动缩成 `0.33x`；行情海啸（波动 `120%`）自动缩成 `0.25x`——**永远把账户风险锁在自己扛得住的舒适区**。

### 生活 / 交易类比
开车跑长途：
- **固定 5x 杠杆** = 不管前方是笔直高速、还是暴雨盘山发卡弯，强行把油门焊死在 180 码。只要遇到一个急弯（正常回撤 `20%`），直接冲下悬崖车毁人亡（爆仓）。
- **波动率目标定仓** = 带路况感知的自适应巡航：晴天直路跑 120 码，暴雨急弯自动降到 40 码。单段路看起来没飙车党刺激，但只有你能稳稳开到终点。

### 在 `MU-USDT-SWAP` 上的真实案例
- **固定高杠杆的惨烈实录**：
  - `MU-USDT-SWAP` 全周期实现年化波动率 **`86.04%`**（前 142 天更高达 **`93.30%`**），动辄回撤 `-34%`、`-36%`、`-53.37%`，完全是加密山寨币级别的剧烈波动。
  - 在前 142 天标的大涨 `+149%` 的超级大牛市里，如果随机找任意一根 K 线开 `5x_isolated_bh`，竟有 **`33.1%`（`4,308 / 13,004`）直接爆仓归零**；而每天调回 5x 的每日再平衡版本，因剧烈的**波动率损耗**，在标的大涨 `+149%` 的行情里居然只赚了 **`+49.47%`**（连 `1x` 现货的三分之一都不到！）。
  - 一进入 6 月 25 日开始的 `-53.37%` 暴跌波段，从高点起算 **`5x`（7 天爆）、`3x`（22 天爆）、甚至 `2x`（11 月 20 日爆）全部触发 `-100%` 强平归零**！暴跌期 `5x` 的任意时点滚动爆仓率高达惊人的 **`94.73%`**（全周期 **`77.46%`**）！
- **Vol-Targeting 救命实录**：
  - 同样一套 96 小时多空趋势信号：不控波动率的固定 `1x` 版 `ls_tsmom_96h` 在全周期最大回撤高达 **`-46.67%`**（暴跌期 `-39.45%`），普通交易者早就心态崩盘砍仓了；
  - 换上 `30%` 目标年化波动率动态定仓的 **`vt_tsmom_96h_ls`** 后，全周期最大回撤直接削去六成多降至 **`-17.38%`**（牛市 `-8.42%`、暴跌 `-16.24%`），且牛市（`+42.74%`）、暴跌（`+11.28%`）、94d 真实窗口（`+7.27%`）、全周期（`+55.99%`）**全部正收益**！
  - 同样地，给隔夜策略仅仅加一条 `90%` 年化波动率上限（高波停手），暴跌波段亏损立刻从 **`-22.19%` 压缩到 `-1.42%`**！

### 实战怎么用（红线判据）
- **杠杆红线**：凡是年化波动率 `> 60%` 的单标的，严禁裸奔使用固定高杠杆（`>= 3x`）。
- **定仓标配**：主力策略应优先采用 **ATR / EWMA 波动率目标定仓**，让单日与单月风险敞口在牛市、震荡、暴跌期始终保持恒定。

## 概念 7：多重检验校正（Deflated Sharpe）与带隔离期的滚动样本外检验（Purged Walk-Forward）

> **核心疑问**：为什么在历史数据上调参 100 次挑出第 1 名，几乎一定会骗自己？怎么搭建"防作弊考场"？

### 一句话直白解释
- **多重检验偏差 & Deflated Sharpe（挤水分夏普 / DSR）**：你试过的策略和参数越多，纯靠撞大运跑出高夏普的概率就越大。**Deflated Sharpe** 就是一把"挤水机"，根据你总共尝试过的试验次数 `N`、历史长度和收益分布的偏斜/尖峰程度，把靠海选挑出来的虚假高夏普里的水分挤干，还原它的真实含金量。
- **带隔离期的滚动样本外检验（Purged Walk-Forward）**：
  - 传统全样本回测 = **先背完考卷答案，再考同一张卷子**（必然满分，毫无意义）。
  - 滚动样本外检验（Walk-Forward）= 用前 3 个月挑参数，参数锁死去考第 4 个月；再用第 2–4 个月挑参数，锁死去考第 5 个月……全程闭卷模拟真实未来。
  - **为什么要"带隔离期（Purged / Embargo）"？** 因为金融交易有持仓跨度与指标记忆（比如一笔单拿了 3 天、均线用了 7 天）：如果训练集截到周一，测试集紧挨着周二开始，周一未平的仓位和重叠的指标信息就会"泄题"给周二。在训练集与测试集之间**刻意清空并隔开一段缓冲空白期**，才能彻底堵死隐形未来函数。

### 生活 / 交易类比
学校想挑出真正的数学学霸，如果采用"给 100 套卷子、允许每个人只上报自己分最高的那一套成绩"（**多重检验不校正**），甚至在考前把原题改个数字放进复习资料（**无隔离期信息泄漏**），那选出来的全是考场赌徒和背题机器，一上真正高考（实盘）立刻不及格。正确的考法是：记录每次摸底成绩（计入试验次数 `N`），考前封卷留隔离期，并且连续考几轮全新联考（**跨周期 + 跨标的 Purged Walk-Forward**）。

### 在 `MU-USDT-SWAP` 上的真实案例
- **多重检验的幻觉**：仓库在 `registry.py` 里注册了整整 **14 个 Fibonacci 预设**（外加历史上探索过的几十组变体）。在 142 天测试中，把 14 个预设全跑一遍挑出最亮眼的 `baseline_green_wide`（`+147.51%`, Daily Sharpe `+3.04`），看起来像是神器——但它连单次检验 `t(Alpha) = +1.25` 都没过，一旦按 `N = 14` 做完多重检验折价（Deflated Sharpe），其真实统计显著性几乎归零！
- **没有滚动样本外检验有多危险**：
  - 142 天内前后半切分（H1: `Mar 4–May 14` vs H2: `May 14–Jul 24`）显示：`direct_next_open` 与 `legacy_break_high` 在前半段狂赚 **`+103.7%`** 和 **`+97.3%`**，结果一进入后半段立刻翻脸大亏 **`-23.3%`** 和 **`-20.5%`**；
  - 放到牛熊大周期更触目惊心：`overnight_price20` 在 113 天牛市（`Mar–Jun`）夏普高达 **`4.98`**、收益 **`+125.35%`**，而一旦步入后 149 天暴跌波段（`Jun–Nov`），立刻反向回撤 **`-22.19%`**；`ladder_tsmom_168h` 更是从牛市 **`+189.25%`**（夏普 `4.99`）断崖崩盘到暴跌期 **`-46.42%`**！

### 实战怎么用（红线判据）
- **如实记账试验次数 `N`**：研究日志必须保留所有失败尝试的次数，不得只挑好看的曲线汇报；用 Deflated Sharpe 给海选冠军挤水分。
- **跨周期 + 跨标的闭卷考**：把全部策略推入带隔离期的滚动样本外框架，并在多只标的（如 `NVDA`/`AAPL`/`TSLA`/`COIN` 永续面板）上盲测通过，才具备进入前瞻模拟盘的资格（对应本仓库 GitHub Issue `#129` 的核心设计思想）。
