# 离线策略 edge 门禁

`python -m mu_strategy.commands.edge_gate --strategy baseline --data-dir data/live` 从可信缓存的 **同一个 current generation** 读取 manifest 中全部股票永续标的。`--days` 默认为 180，`--simulations` 默认为每标的 200，`--seed` 默认为 1；`--funding-annual` 默认为 0.08，`--z-threshold` 默认为 2。没有 `--symbol` 子集参数。缺少标的、15m/1h 数据未发布、缓存内容不可信或过期时，命令非零退出，不产生新报告。命令不刷新、不联网、不写 `data/live`。

默认报告目录为 ignored 的 `reports/live/edge_gate/<generation>-<strategy>-seed<seed>-n<simulations>-<parameter-digest>/`，也可用 `--output-dir` 指定。命令 stdout 只输出 JSON、Markdown 的绝对路径。报告包含 Git commit、generation ID、seed、参数、各标的收益与零分布、横截面统计和失败项。相同代码、generation、seed、参数产生相同文件内容；报告不写运行时间戳。

## 零假设与判定

每个标的的零假设是：该策略在该标的 15m 收益结构上没有可迁移的择时能力。完整 UTC 日必须从 00:00 起连续包含 96 根 15m K 线。完整日按工作日与周末分层，在相同层的完整日中有放回抽样，整块对齐放到目标日期；首尾残日及有缺口的日保留原位置与原始收益。每根有前收盘价的 bar 都以相对前一根 close 的对数收益计算，并减去全样本平均漂移；路径首根没有前收盘价，保留为价格锚点，不能作为后续完整日的首根收益来源。某层在目标中出现却没有完整日可抽时直接失败。真实与合成路径都从各自 15m K 线聚合 1h context；传入的可信 1h 必须与聚合结果一致。两者用相同的 `run_backtest`、策略配置及成本计算重跑。实际扣成本收益在合成收益中的中位秩分位即该标的分位；完全相同的结果记为 50 分位。

这个零分布打破跨日顺序和样本漂移，不等于证明所有可能的日内结构无效。它不能作为参数搜索或择优后的显著性修正。固定持仓期随机放置不进入门禁：移动止损、加仓和退出规则会改变暴露与持仓期，强制放置固定持仓段不能复现引擎的条件路径；实测在无 edge 路径也会给出虚高分位。

横截面零假设是标的级分位均值为 50。每个标的只贡献一个观测值，标准误取标的间样本标准差除以 √N 与均匀零分布标准误 `100/√(12N)` 的较大值；不把同一时刻的多标的 K 线当独立样本。同一时刻跨标的冲击会使逐 K 线 t 值虚高，标的级聚合仍有共同市场相关性风险，所以报告给出分位、标准误、>90 分位标的数及零假设期望 `N×0.1`，并同时要求持有基准胜率。

判定在代码中固定为两项都成立才 **PASS**：`(mean_percentile − 50) / SE ≥ 2`（阈值可由 `--z-threshold` 覆盖），且扣成本策略收益**严格跑赢**同窗 1x 持有的标的比例 `>50%`。其他情况 **FAIL**，报告逐项列出失败检查。>90 分位数及波动缩放持有是诊断指标，不会暗中改变这两项规则。门禁默认 FAIL；没有可用标的、数据错误或任何未能算完的标的均不产生 PASS。

## 成本与基准口径

策略用现有 `with_fee_profile(config, "market")`，每侧 taker 5bp，往返基准为 10bp。资金费按每笔成交的实际多头单位数，从成交 K 线时间标签到平仓标签逐根用 `units × 15m close × elapsed_ms / (365×24×3600×1000) × funding_annual` 扣除；加仓从自身成交时刻起计。默认年率 8%，不读交易所 funding 历史。回测引擎本身不变，资金费在每次引擎运行后从权益中扣除，所以不会反向改变该次运行中后续交易的仓位大小。

同窗 1x 买入持有从首根收盘到末根收盘，承担同样每侧 taker 费和该期间的多头资金费。波动缩放持有的名义倍率为策略已实现净权益 15m 收益波动率除以 1x 持有 15m 收益波动率，其扣成本收益按倍率线性缩放；未计杠杆下的波动拖累，持有波动为零时倍率记为零。波动缩放持有只是诊断指标，不参与判定；PASS 仅使用 1x 基准。该比较是离线研究证据，不授予自动晋升或交易权限。
