# 来源策略用在 MU：行业动量过滤候选（2026-09-13）

用户要求的是“这些策略用在 MU 上，给出一个优化的 MU 策略”。之前只做原 ETF 的组合研究，没有交付 MU 策略，是交易对象理解偏差。本文所有收益来自 **MU-USDT-SWAP 合约成交**；外部股票/行业数据只提供信号，不把正股历史接成合约价格。

## 行业动量轮动是什么，如何实施

原仓库 [sector-momentum-rotational-system.py](https://github.com/paperswithbacktest/awesome-systematic-trading/blob/4e23dd84c9ff746ddfcbc856316bcbcef0855b81/static/strategies/sector-momentum-rotational-system.py) 在 VNQ、XLK、XLE、XLV、XLF、XLI、XLB、XLY、XLP、XLU 中，每月以过去 252 个交易日涨幅排名，持有前三，各 1/3。它交易多个行业，而非预测一只股票的明日涨跌。原实施需要这些 ETF 的日线、月初调仓任务和可交易 ETF 的账户。

**用于 MU 的具体候选：以行业排名决定 MU 是否持仓。** 保留原排名资产池、252 日周期、前三门槛和月度频率，把科技行业 XLK 是否进入前三映射为 MU 多头/现金。这是明确的 MU 迁移规则，不声称原论文直接证明了 MU 会获利。

1. 每个美股月初首个交易日，使用前一已完成交易日的复权收盘价，计算十只 ETF 的 `close[-1] / close[-253] - 1`，降序排名。
2. XLK 在前三：无仓时买入 MU-USDT-SWAP，名义持仓为入场时账户净值的 1 倍；有仓则继续持有原数量。
3. XLK 不在前三：平掉 MU，持现金，等待下月再评估。
4. 信号在美股月初开盘时生效，本轮以此后的首个整点 UTC 小时开盘价成交。原月初09:30美东对应夏令时13:30UTC、冬令时14:30UTC，因此模拟分别在14:00/15:00UTC执行。
5. 不做原 Fibonacci 二次回踩、阶梯加仓或 5 倍放大；这一候选只有月度退出，没有另外叠加未经测试的固定止损。

主要变化是用行业强弱决定 MU 的持有时段；不能称为直接复制 ETF 轮动持仓。它仍然高度暴露于 MU 价格，不能消除单股回撤。

## 在 MU 上实际比较了什么

MU trusted generation `c6a16255ecda480299f84081e014e3f8`，UTC `[2026-03-16, 2026-09-11)`，179 天。MU 正股 1990–2026 日线提供原长周期信号历史；十只行业 ETF 来自已缓存的原资产池。信号使用时间与合约成交时间单独管理。日线 ATR 信号在常规美股收盘后15分钟才可见，随后首个整点执行，休市期间不凭空生成新日线。

| 移植到 MU 的规则 | 保留的来源 | 明确变化 |
|---|---|---|
| 行业过滤 | 行业252日动量、前三、月调仓 | XLK成员资格→只持MU，不买ETF |
| 210日均线趋势 | asset-class-trend-following | 单标的MU正股均线信号→MU合约，多资产配权删除 |
| 252日方向动量 | time-series-momentum-effect | 保留252个日收盘、月调仓方向；负信号现金，未复现多期货逆波动率配权 |
| 新高＋ATR10 | trend-following-effect-in-stocks | 初始化2520日最高收盘后持续更新，Wilder ATR10、1ATR上移退出位；改为正股收盘确认退出，非原盘中stop-market |
| 一月效应 | january-barometer | 判断MU一月涨跌，现金替代BIL |
| 月末/月初效应 | turn-of-the-month-in-equity-indexes | 月末末交易日开盘至次月第三个交易日收盘，SPY→MU；按下一整点成交 |
| 发薪日效应 | payday-anomaly | 15日（周末前移周五）收盘前1分钟至下一交易日同一时刻，SPY→MU，下一整点成交；遇非周末假日不擅自移动 |
| BTC时段效应 | intraday-seasonality-in-bitcoin | 保留UTC22:00–00:00，BTC→MU |
| 新高/ATR加行业过滤 | 上述两项明确组合 | 交集持仓，用以测试行业过滤是否改善新高策略 |

没有将252日改成168小时。三个低频信号（均线、方向动量、一月效应）在首60天的MU仓位完全相同，选权重时只保留一个代表；完整候选结果仍全部展示。新高/ATR的执行改动可能显著影响表现，因此不把结果称为原论文复现。

首次执行曾套用旧实验的“首段至少3笔”筛选，结果错误地把月度策略全部排除。本轮取消该活动量门槛，对固定来源候选进行比较；低交易数留在结果里解释，而非让门槛替用户决定不能研究。

首60天只识别相同仓位信号，并用于后续同分时的排序；中60天对七个不同信号代表和现金比较 **330** 个25%步长资金分配，以回撤不超过同段MU买入持有为约束最大化收益。选择100%行业过滤子账户。由于月度慢信号在中段也完全相同，行业过滤胜出依赖首段表现的同分规则，不是中段证明它优于所有趋势规则。最后59天只展示，不改参数和权重。这179天已在前几轮研究中看过，不能称为全新外部样本。

组合搜索没有给出优于单个行业过滤信号的分配，故不为“策略组合”强行增加亏损组件。可以把部分初始本金留现金，但这只改变资金配置，并不创造新信号：

这里是初始本金分账户，之后不再平衡；盈利会让风险账户占比上升，因此不能把“初始50%”理解为始终50%净值敞口，也不能把40.28%回撤简单除以二。

**给出的 MU 优化候选是行业动量过滤1x，但提升证据有限。** 全期比MU买入持有多47.56个百分点，来源是避开3月份的一段下跌；3月XLK仅排第5，4月进入第2，于4月1日14:00UTC以355.73入场，之后一直持有至数据末尾结算972.33。全期仅一次入场，后59天表现与直接持有一样，不能声称已经形成稳定超额收益。它比原baseline当前5x全期收益高31.12个百分点，但回撤多17.23个百分点，最后59天收益反而少4.20个百分点。因此暂不建议直接替换当前配置。若目标同时是不增加原baseline风险并提高收益，本次尚未找到满足条件的替代策略。

独立复核发现既有小时成交函数对显式已知目标也跳过第一根行情，导致初版基准晚一小时入场、收益少算。已以真实首小时回归先红后绿，仅允许显式目标在首根成交，依赖历史的旧信号路径保持原规则。本表使用修正后的430.71起点开盘，而非下一小时435.20；候选行业过滤的4月入场不受此问题影响。
