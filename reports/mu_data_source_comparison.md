# MUUSDT Data Source Comparison

目标：确认能否用 OKX 或公开归档补齐 `MUUSDT` 更长历史，并在更长样本上比较 `baseline` 与 `baseline_half_protect`。

## 数据源可用性

| 数据源 | 标的 | 15m 最早可用 | 1h 最早可用 | 结论 |
|---|---|---|---|---|
| Binance REST `fapi/v1/klines` | `MUUSDT` | 2026-04-07 13:15 UTC | 2026-04-07 13:00 UTC | 当前项目原始数据源，约 65.6 天 |
| Binance 官方公开归档 S3 | `MUUSDT` | 2026-04-07 | 2026-04-07 | 公开归档没有补到更早 |
| OKX public API | `MU-USDT-SWAP` | 2026-03-04 07:15 UTC | 2026-03-04 07:00 UTC | 当前可用最长来源，约 99.9 天 |

## OKX 样本回测

数据文件：

- `data/OKX_MU-USDT-SWAP_15m_180d.csv`
- `data/OKX_MU-USDT-SWAP_1h_180d.csv`

请求参数为 180 天，但 OKX 当前只能返回从 `2026-03-04` 开始的数据；原因是 `MU-USDT-SWAP` 本身是较新合约，无法通过该合约数据补出真正半年的历史。

## 判断

- OKX 可用，且比 Binance 多出约 34 天样本，但仍不是完整半年。
- OKX 样本下 `baseline` 总收益更高；`baseline_half_protect` 胜率更高，但平均亏损更大，最终收益被拖低。
- Binance 官方公开归档能作为 REST 数据的校验来源，但目前不能补齐 `MUUSDT` 更早历史。
- 如果一定要做真正半年，需要换研究对象：用底层美股 `MU` 的股票行情重建信号，或找支持 `MU` token/合约上市前合成价格的付费/第三方数据商；这会改变交易标的和成交假设，不能和当前合约回测直接等同。

研究用途，不构成投资建议。
